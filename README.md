# API RESTful Profesional: Gestión de Artes Marciales (DWES)

Proyecto completo desarrollado con **Spring Boot 3.4**, **Java 21**, **Spring Data JPA**, **H2 Database**, **Caché RAM**, **RestClient** y **Swagger UI**.

## URLs Útiles al Arrancar (`http://localhost:8080`)
- **Swagger UI:** http://localhost:8080/swagger-ui.html
- **Consola H2 (Perfil dev):** http://localhost:8080/h2-console (JDBC URL: `jdbc:h2:mem:artesmarciales_dev`, User: `sa`, Password: vacío)
